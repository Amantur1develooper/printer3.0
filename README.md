# Онлайн Принтер

## Быстрый старт

### 1. Требования
- Docker и Docker Compose (установить с docker.com)
- На ноутбуке с принтером: Python 3.8+

### 2. Первый запуск

```bash
# Клонировать/скопировать папку проекта
cd onlineprinter3

# Запустить автоматическую настройку
bash setup.sh
```

Скрипт:
- Создаст `.env` из шаблона
- Соберёт и запустит контейнеры
- Применит миграции базы данных
- Создаст аккаунт администратора
- Заполнит тарифы и остатки бумаги

### 3. Настройка `.env`

Откройте `.env` и заполните:

```env
SECRET_KEY=длинная-случайная-строка  # python -c "import secrets; print(secrets.token_hex(32))"
DEBUG=False
ALLOWED_HOSTS=localhost,192.168.1.xxx,ваш-домен.com

PAYMENT_PHONE=+996 700 123456       # Ваш номер для приёма оплаты
PAYMENT_RECIPIENT=Ваше имя

DB_PASSWORD=надёжный-пароль
```

### 4. Управление контейнерами

```bash
docker compose up -d          # Запустить
docker compose down           # Остановить
docker compose logs -f web    # Смотреть логи
docker compose restart web    # Перезапустить после изменений
```

## Настройка принтера

### Шаг 1: Создать терминал в админке

1. Зайти на `http://ВАШ-СЕРВЕР/admin`
2. `Терминалы принтеров` → `Добавить`
3. Ввести название (например "Принтер HP офис")
4. Сохранить и **скопировать токен** (UUID)

### Шаг 2: Запустить клиент на ноутбуке

```bash
# Установить зависимости
pip install requests

# Запустить клиент (заменить IP и токен)
python printer_client.py \
  --server http://192.168.1.100 \
  --token xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

Клиент будет опрашивать сервер каждые 10 секунд и автоматически печатать новые заказы.

**Windows:** Установить [SumatraPDF](https://www.sumatrapdfreader.org/) для печати PDF.  
**Linux/Mac:** Используется стандартная команда `lp`.

## Работа с заказами (Админка)

Адрес: `http://ВАШ-СЕРВЕР/admin`

### Подтверждение оплаты

1. `Заказы` → найти заказ со статусом "Чек загружен"
2. Открыть заказ, посмотреть фото чека
3. Выбрать заказ → `Действия` → **Подтвердить оплату (paid)**
4. Статус автоматически станет "В очереди" → принтер напечатает

### Управление тарифами

`Тарифы` → можно менять цены прямо в таблице.

Текущие тарифы по умолчанию:
| Формат | Цвет | Тип | Цена |
|--------|------|-----|------|
| A4 | Ч/Б | Односторонняя | 5 сом |
| A4 | Ч/Б | Двусторонняя | 4 сом |
| A4 | Цветная | Односторонняя | 15 сом |
| A4 | Цветная | Двусторонняя | 12 сом |

### Управление бумагой

`Остатки бумаги` → обновлять количество при пополнении.

Если бумаги меньше порога (`MIN_PAPER_THRESHOLD=5`), заказ не принимается.

### Статистика

Админка → `Статистика` (ссылка в меню) — выручка, заказы, листы, ошибки.

## Поток работы системы

```
Пользователь загружает PDF
    → Система считает страницы (pypdf)
    → Пользователь выбирает параметры
    → Live-расчёт стоимости (AJAX)
    → Проверка остатка бумаги
    → QR-код с реквизитами оплаты
    → Пользователь переводит деньги и загружает чек
    → Администратор проверяет чек в админке
    → Подтверждает оплату → статус: "В очереди"
    → Клиент принтера (ноутбук) забирает задание
    → Скачивает PDF, отправляет на принтер
    → Отчитывается серверу → статус: "Распечатан"
    → Пользователь видит статус на странице отслеживания
```

## API для принтера

| Метод | URL | Описание |
|-------|-----|---------|
| GET | `/api/printer/jobs/?token=<uuid>` | Получить следующее задание |
| POST | `/api/printer/jobs/<id>/pickup/?token=<uuid>` | Взять в работу |
| POST | `/api/printer/jobs/<id>/complete/?token=<uuid>` | Завершено |
| POST | `/api/printer/jobs/<id>/error/?token=<uuid>` | Ошибка |

## Часто задаваемые вопросы

**Как добавить онлайн-оплату?**  
После договора с банком заменить `payment_view` в `orders/views.py` на интеграцию с API банка. Текущая схема (QR + чек) остаётся как fallback.

**Как увеличить лимит размера файла?**  
В `.env`: `MAX_FILE_SIZE_MB=100`. В `nginx.conf`: `client_max_body_size 200M;`

**Как посмотреть логи принтера?**  
На ноутбуке клиент выводит всё в консоль. Для работы в фоне:
```bash
nohup python printer_client.py --server ... --token ... > printer.log 2>&1 &
```
